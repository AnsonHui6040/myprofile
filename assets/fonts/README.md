# Website typography

Michroma Regular is a local companion face chosen for its rounded rectangular Latin letterforms. It is not claimed to be the unknown original typeface: the supplied logo SVG contains traced paths, not font metadata.

Source: https://github.com/googlefonts/Michroma-font/blob/master/fonts/webfonts/Michroma-Regular.woff2
License: SIL Open Font License 1.1, retained in OFL-Michroma.txt.

Chinese glyphs use Noto Sans TC. The hero I’m mark is custom SVG artwork in ../brand/im-monogram.svg, drawn with uniform strokes and rendered at its native aspect ratio.
